# カラースキーム定義

## カラーパレット

### ベースカラー（Background）

| トークン名       | カラーコード | 用途                                           |
| ---------------- | ------------ | ---------------------------------------------- |
| bg-primary       | `#edf0ef`    | ページ背景                                     |
| bg-surface       | `#f5f7f6`    | カード、リストアイテム、入力フィールドの背景   |
| bg-surface-hover | `#eaf0ed`    | サーフェスのホバー状態                         |
| bg-placeholder   | `#dce5e1`    | サムネイルプレースホルダー、画像未読み込み領域 |

### プライマリカラー（Primary）

| トークン名    | カラーコード | 用途                   |
| ------------- | ------------ | ---------------------- |
| primary       | `#1a5c5c`    | ボタン、アクティブ要素 |
| primary-hover | `#003333`    | ボタンのホバー状態     |

### テキストカラー（Foreground）

| トークン名    | カラーコード | 用途                                       |
| ------------- | ------------ | ------------------------------------------ |
| fg-primary    | `#0d2626`    | 見出し                                     |
| fg-default    | `#1a2e2e`    | 本文テキスト                               |
| fg-secondary  | `#2a4040`    | カード内の補足テキスト                     |
| fg-muted      | `#7a9a90`    | パンくずリスト、キャプション、補助テキスト |
| fg-on-primary | `#f0f6f4`    | プライマリボタン上のテキスト               |

### ボーダーカラー（Border）

| トークン名     | カラーコード | 用途                               |
| -------------- | ------------ | ---------------------------------- |
| border-default | `#d4ddd9`    | カード枠、リストアイテムの区切り   |
| border-hover   | `#7a9a90`    | ホバー時のボーダー強調             |
| border-focus   | `#5a7a72`    | フォーカス時、画像グリッドのホバー |

### デンジャーカラー（Danger）

| トークン名      | カラーコード | 用途                           |
| --------------- | ------------ | ------------------------------ |
| danger          | `#cc4444`    | 削除ボタンのテキスト・ボーダー |
| danger-hover-bg | `#cc4444`    | 削除ボタンのホバー背景         |
| danger-hover-fg | `#ffffff`    | 削除ボタンのホバーテキスト     |

## タイポグラフィ

| 要素           | フォントサイズ | ウェイト       |
| -------------- | -------------- | -------------- |
| 見出し（h1）   | 22px           | SemiBold (600) |
| 本文・リスト   | 15px           | Regular (400)  |
| ボタン         | 14px           | Regular (400)  |
| パンくずリスト | 13px           | Regular (400)  |
| キャプション   | 11px           | Regular (400)  |
