# 作品詳細画面

## 画面概要

選択した作品の巻一覧を表示する画面。

---

## 画面構成

### 入力項目

なし

### 出力項目

| 項目名       | 説明                                | 表示条件                 |
| ------------ | ----------------------------------- | ------------------------ |
| 作品タイトル | 作品名を見出しとして表示            | 常に表示                 |
| 戻るリンク   | 作品一覧画面へ戻るリンク            | 常に表示                 |
| 巻リンク     | 「第N巻」形式のクリック可能なリンク  | 巻が1件以上存在する場合   |

- 巻リンクは巻番号の昇順で表示する
- 巻にタイトルはなく、番号のみで表示する
- 巻リンクをクリックすると、その巻のビューアー画面へ遷移する
- 存在しない作品、または巻が0件の作品を指定した場合は、エラー画面を表示する

---

## 既読機能

- 「既読管理」ボタンを押すと編集モードに入る
  - 編集モード中はカードのタップで既読/未読を切り替える
  - 編集モード中はビューアーへの遷移は行わない
  - 「既読管理を終了」ボタンで通常モードに戻る
- 既読の巻はカード全体がグレーアウトする（サムネイル薄表示・グレースケール、背景・テキストもグレー）
- 既読状態はユーザー単位でDBに保存され、リロード後も維持される

---

## 画面遷移

```mermaid
graph TD
  A[作品詳細画面] -->|戻るリンク| B[作品一覧画面]
  A -->|巻リンクをクリック| C[ビューアー画面]
  A -->|既読管理ボタン| D[編集モード]
  D -->|カードをタップ| D
  D -->|既読管理を終了| A
```
